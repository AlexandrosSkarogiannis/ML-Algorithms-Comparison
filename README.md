# ML-Algorithms-Comparison
# Σύγκριση Αλγορίθμων Μηχανικής Μάθησης (OpenML Datasets)

Αυτό το repository περιέχει την πειραματική σύγκριση τριών κλασικών αλγορίθμων μηχανικής μάθησης σε προβλήματα ταξινόμησης (classification), χρησιμοποιώντας δεδομένα από το OpenML[cite: 3]. Υλοποιήθηκε σε Python (scikit-learn) στα πλαίσια ακαδημαϊκής εργασίας.

##  Δεδομένα (Datasets)
Χρησιμοποιήθηκαν τρία datasets διαφορετικής δυσκολίας και δομής:
* **breast-w**: Πρόβλεψη καρκίνου του μαστού (Binary classification)[cite: 3].
* **diabetes**: Πρόβλεψη διαβήτη (Αποκλειστικά αριθμητικά χαρακτηριστικά)[cite: 3].
* **credit-g**: Εκτίμηση πιστωτικού κινδύνου (Μικτά χαρακτηριστικά: αριθμητικά και κατηγορικά)[cite: 3].

## Αλγόριθμοι που εξετάστηκαν
1. **k-Nearest Neighbors (k-NN)**[cite: 3]
2. **Random Forest**[cite: 3]
3. **Multi-Layer Perceptron (MLP Classifier / Neural Net)**[cite: 3]

##  Μεθοδολογία & Προεπεξεργασία
Η ροή εργασίας (pipeline) περιλαμβάνει:
* **Χειρισμό ελλιπών τιμών (Imputation):** Συμπλήρωση κενών τιμών (π.χ. με τη μέση τιμή)[cite: 3, 6].
* **Κανονικοποίηση (Scaling):** Χρήση `StandardScaler` για την ομαλή εκπαίδευση των αλγορίθμων που βασίζονται σε αποστάσεις (k-NN) ή βάρη (MLP)[cite: 4, 6].
* **Κωδικοποίηση (Encoding):** Χρήση `One-Hot Encoding` για τις κατηγορικές μεταβλητές (απαραίτητο για το credit-g)[cite: 4, 6].
* **Αξιολόγηση:** Εφαρμογή **5-fold Cross-Validation**[cite: 3, 6] με βάση τις μετρικές *Accuracy, Precision, Recall* και *F1-score (macro-averaged)*[cite: 3].

##  Βασικά Συμπεράσματα
* Ο **Random Forest** παρουσίασε την καλύτερη και πιο σταθερή απόδοση συνολικά, επιτυγχάνοντας ακρίβεια 96.71% στο `breast-w` και 75.40% στο `credit-g`[cite: 4]. Διαχειρίζεται εξαιρετικά τα μικτά δεδομένα χωρίς να απαιτεί εξαντλητικές ρυθμίσεις[cite: 4, 5].
* Το **MLP (Νευρωνικό Δίκτυο)** πέτυχε υψηλή ακρίβεια (76.44% στο `diabetes`), ωστόσο αποδείχθηκε ο πιο ευαίσθητος αλγόριθμος στις υπερπαραμέτρους και απαιτεί αυστηρή κανονικοποίηση δεδομένων για να συγκλίνει[cite: 4, 5].
* Ο **k-NN** ήταν γρήγορος και αποτελεσματικός σε απλά datasets (`breast-w`), αλλά υστέρησε σημαντικά στο `credit-g` (61.20% F1-Score) λόγω του μεγάλου αριθμού χαρακτηριστικών που προέκυψαν μετά το One-Hot Encoding[cite: 4, 5].
