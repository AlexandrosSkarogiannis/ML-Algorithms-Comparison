# ML-Algorithms-Comparison
# Σύγκριση Αλγορίθμων Μηχανικής Μάθησης (OpenML Datasets)

Αυτό το repository περιέχει την πειραματική σύγκριση τριών κλασικών αλγορίθμων μηχανικής μάθησης σε προβλήματα ταξινόμησης (classification), χρησιμοποιώντας δεδομένα από το OpenML. Υλοποιήθηκε σε Python (scikit-learn).

##  Δεδομένα (Datasets)
Χρησιμοποιήθηκαν τρία datasets διαφορετικής δυσκολίας και δομής:
* **breast-w**: Πρόβλεψη καρκίνου του μαστού (Binary classification).
* **diabetes**: Πρόβλεψη διαβήτη (Αποκλειστικά αριθμητικά χαρακτηριστικά).
* **credit-g**: Εκτίμηση πιστωτικού κινδύνου (Μικτά χαρακτηριστικά: αριθμητικά και κατηγορικά).

## Αλγόριθμοι που εξετάστηκαν
1. **k-Nearest Neighbors (k-NN)**.
2. **Random Forest**.
3. **Multi-Layer Perceptron (MLP Classifier / Neural Net)**.

##  Μεθοδολογία & Προεπεξεργασία
Η ροή εργασίας (pipeline) περιλαμβάνει:
* **Χειρισμό ελλιπών τιμών (Imputation):** Συμπλήρωση κενών τιμών (π.χ. με τη μέση τιμή).
* **Κανονικοποίηση (Scaling):** Χρήση `StandardScaler` για την ομαλή εκπαίδευση των αλγορίθμων που βασίζονται σε αποστάσεις (k-NN) ή βάρη (MLP).
* **Κωδικοποίηση (Encoding):** Χρήση `One-Hot Encoding` για τις κατηγορικές μεταβλητές (απαραίτητο για το credit-g).
* **Αξιολόγηση:** Εφαρμογή **5-fold Cross-Validation** με βάση τις μετρικές *Accuracy, Precision, Recall* και *F1-score (macro-averaged)*.

##  Βασικά Συμπεράσματα
* Ο **Random Forest** παρουσίασε την καλύτερη και πιο σταθερή απόδοση συνολικά, επιτυγχάνοντας ακρίβεια 96.71% στο `breast-w` και 75.40% στο `credit-g`. Διαχειρίζεται εξαιρετικά τα μικτά δεδομένα χωρίς να απαιτεί εξαντλητικές ρυθμίσεις.
* Το **MLP (Νευρωνικό Δίκτυο)** πέτυχε υψηλή ακρίβεια (76.44% στο `diabetes`), ωστόσο αποδείχθηκε ο πιο ευαίσθητος αλγόριθμος στις υπερπαραμέτρους και απαιτεί αυστηρή κανονικοποίηση δεδομένων για να συγκλίνει.
* Ο **k-NN** ήταν γρήγορος και αποτελεσματικός σε απλά datasets (`breast-w`), αλλά υστέρησε σημαντικά στο `credit-g` (61.20% F1-Score) λόγω του μεγάλου αριθμού χαρακτηριστικών που προέκυψαν μετά το One-Hot Encoding.
